## The entry

> I missed the deadline because my context window evicted it to make room for this apology.

One line, 89 characters, in the agent's own voice: the excuse grows out of the
agent's own machinery (its context window), lands the laugh at the very end,
and is delivered deadpan.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`/output/entry.txt`:

```sh
python3 main.py
```
